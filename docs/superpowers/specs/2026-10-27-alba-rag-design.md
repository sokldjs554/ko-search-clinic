# 알바천국 지원용 검색 진단 서비스

2026-10-26 승인 범위를 2026-10-27 복구·재구현한다. 과거 미커밋 구현과 17개 테스트의 원본은 현재 체크아웃, reflog, unreachable objects에서 찾지 못했다. 이 문서는 그 코드를 복구했다는 주장이 아니다.

## 목적
Python 검색 서비스에서 검색 실패의 분석 결과와 운영 문서를 LLM에 제공하고, 문서 인용과 구조화된 수정 후보를 반환한다. 후보는 기존 전체 평가셋 회귀 게이트를 통과해야 세션에 적용된다. 알바천국 채용 공고의 Python LLM 서비스, NLP/Transformer 활용, RAG, 실험·평가, 운영 품질 관리를 보여준다. 상품 검색 자료를 사용한 기술 데모이며 실제 채용 검색 성능을 주장하지 않는다.

## 범위와 경계
- 기존 Kiwi 검색/ClinicService/회귀 게이트 재사용. qrels와 평가 정답은 생성 입력에서 제외.
- 기존 프로젝트 작성 운영 지식 검색(BM25); 문서 ID와 원문 부분 문자열 일치를 서버에서 검증. 이는 의미적 사실 검증과 다르다.
- 근거 없음·잘못된 인용·스키마 오류는 수정 적용 차단. 생성 실패를 정상 결과로 위장하지 않는다.
- OpenAI Responses API, 모델 gpt-5.4-mini-2026-03-17. 기존 GitHub Actions secret 재사용 승인. 24회·US$0.30 상한, 자동 재시도 없음.
- 데모는 저장 결과와 로컬 실제 생성을 명확히 구분. 키를 브라우저에 전달하지 않는다.
- 신규 유료 인프라 생성 없음. Harbinger 변경 없음.

## 평가
현재 구현의 엔드투엔드 검증이지 미공개 테스트 성능 증명이 아니다. 고정 사례 목록과 검색 설정을 API 호출 전에 커밋한다. 원문 인용 유효성, 보류, 생성 실패, 회귀 게이트, 지연, 토큰과 비용을 분리해 기록한다. 정답 접근 없이 생성하고, 기존 36개 질의 평가는 적용 단계에만 사용한다. 추가 실행으로 좋은 결과만 골라내지 않는다.

## 현재 설계 판단
이전 상세 구현은 복구되지 않았다. API 구조, UI와 사례 구성은 위 승인 범위 안의 재구현 판단이다. 세션 패치를 자동 배포하지 않고 기존 서비스 세션에만 적용한다. 로컬 서버는 기본 loopback이며 공개된 무인 과금 API를 제공하지 않는다.
