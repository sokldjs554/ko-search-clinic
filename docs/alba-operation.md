# 실행과 운영 범위

## 저장 결과

README의 두 명령만 실행한다. `/demo/`에서 저장 결과를 읽고 JSON을 내려받는다. 저장 결과는 최초 응답 + 현재 검증기의 오프라인 재검증이며 API 새 생성이 아니다.

## 로컬 실제 생성

서버 실행 환경에 `OPENAI_API_KEY`, 24자 이상의 무작위 `CLINIC_LIVE_TOKEN`, `CLINIC_ENABLE_LIVE=1`을 설정한다. 키는 셸 기록·소스·브라우저에 넣지 말고 사용하는 환경의 비밀값 설정을 이용한다. 브라우저에는 API 키 대신 로컬 운영 토큰만 입력한다. 토큰은 화면 메모리에만 두며 저장하지 않는다.

기본 바인딩은 `127.0.0.1:8000`. 생성·적용 경로만 운영 토큰으로 보호한다. 기존 검색/세션 API 전체를 공개 서비스 인증으로 전환한 것은 아니다. 인터넷에 그대로 노출하지 않는다.

`CLINIC_BUDGET_PATH` 기본값 `.clinic-budget.json`: 요청 전에 최대 비용을 예약하고 실패도 환급하지 않는다. 같은 장부를 쓰는 프로세스는 배타 파일로 갱신한다. 충돌·손상·프로세스 종료로 남은 잠금은 계속 과금하는 대신 멈춘다. 장부 삭제는 비용 한도를 초기화하므로 자동 정리하지 않는다.

**2026-10-27 승인 캠페인은 24회를 모두 사용했다.** 이번 문서의 실행 안내가 추가 호출 승인을 의미하지 않는다. 저장 응답 재검증은 무료로 가능하다. 다른 로컬 사용자의 새 호출은 자신의 별도 API 사용 결정과 예산에 따른다.

## 처리 흐름

1. 입력 길이와 운영 토큰 검사.
2. 질의 형태소·검색 상위 3건·운영 문서 상위 3건을 구성. 평가 정답표 제외.
3. 제한된 Responses API 요청. 응답 상태·스키마·원문 인용·후보 규칙 검사.
4. 사람이 검사를 요청하면 새 세션에서 전체 평가셋 검사. 기준 미달은 기각.
5. 결과/지연/토큰/비용/차단 사유 보존. 생성과 적용은 별도 동작.

문서 본문은 400자로 제한한다. 이 상한은 비용·입력 제어를 위한 구현값이며 최적 청킹 크기로 검증한 값은 아니다. BM25 검색을 선택해 자료와 순위를 로컬에서 재현하도록 했다. 기존 dense/hybrid 구현은 보존했지만 이번 실제 생성 실험은 BM25만 사용했다.

## 모니터링

`GET /explanation-status`: 현재 프로세스의 요청 수, 지원/보류/차단, 상류 오류, 바쁨 응답, 게이트 요청 수, 최근 100회 nearest-rank p95. 게이트 카운터는 멱등 재요청을 포함하는 **요청 수**다. 다중 인스턴스 집계나 영구 운영 통계가 아니다.

HTTP 429는 동시 생성 중임을, 502는 상류 오류·예산 중단 등 생성 경로 실패를 뜻한다. 브라우저 취소는 결과 수신을 중단하며 이미 시작한 원격 계산의 취소·환불을 보장하지 않는다.

## 기술 선택의 범위

GPT API로 관측 요약·실패 유형 분류·수정 후보 생성을 수행한다. 사전학습·미세조정은 하지 않았다. RAG는 모델 내부 지식을 수정하는 학습 방식이 아니라 이번 요청에 검색한 문서를 함께 주는 구성이다. 생성 설명의 자연스러움, 출처 일치, 실제 검색 개선은 각각 별도 확인이 필요하다.

LangChain/LlamaIndex 없이 직접 모듈을 연결했다. 현재는 입력·출력·회귀 검사 경계를 직접 추적하기 위한 선택이다. 이 선택을 해당 프레임워크 사용 경험으로 적지 않는다. API 사용만으로 Transformer 내부 구조에 대한 지원자의 이해 수준을 증명하지 않는다.
