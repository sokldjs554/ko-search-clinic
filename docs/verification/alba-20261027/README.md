## 처음 발견한 실패

원문과 모델 인용을 바이트 그대로 대조했을 때 24건 중 12건이 차단됐다. 이를 모두 모델의 사실 오류로 해석하면 안 된다. 일부 인용은 줄바꿈이나 Markdown 강조 기호만 달랐다. 단어가 바뀐 사례, 지식 문서 대신 상품 ID를 인용한 사례, 잘못된 복합어 패치도 있었다.

## 후처리 보완과 재검증

연속 공백·줄바꿈을 한 칸 공백으로 바꾸고 짝이 맞는 `**강조**` 표시만 비교용으로 제거했다. 단어 사이 공백과 원본 위치를 보존한다. 일치하면 표시할 인용을 **제공된 본문에 실제 존재하는 부분 문자열**로 돌려놓는다. 단어·문장부호·대소문자는 바꾸지 않는다. 원본 모델 출력은 수정하지 않고 별도 보존한다.

같은 24개 응답을 재검사했다. 모델을 다시 호출하거나 재학습한 결과가 아니며, 실패를 본 뒤 보완한 **사후 검증**이다. 독립 사례에서 재현되는지는 아직 확인하지 않았다.

| 조건 | 최초 검증: 지원/보류/차단 | 보완 후: 지원/보류/차단 |
|---|---|---|
| 검색 문서 제공 12건 | 1 / 1 / 10 | 6 / 2 / 4 |
| 검색 문서 제거 12건 | 0 / 10 / 2 | 0 / 10 / 2 |

여기서 ‘지원’은 형식·원문 근거 조건을 통과했다는 뜻이다. 진단이 정확하거나 수정이 효과적이라는 뜻은 아니다. 문서 제거 조건의 2건은 존재하지 않는 지식 출처로 차단됐으며, 최종 적용된 수정은 0건이다.

지원 판정 6건의 후보를 기존 36개 질의로 검사했다. 각 사례는 새 세션이며 누적 개선 성능이 아니다.

| 질의 | 표적 nDCG 전/후 | 판정 |
|---|---|---|
| 도너츠 | 0 → 1.0000 | 채택, 회귀 없음 |
| 블루투스 스피커 | 0.5000 → 1.0000 | 채택, 회귀 없음 |
| 핸드폰 | 0 → 0.5364 | 채택, 회귀 없음 |
| 케잌 주문 | 0 → 1.0000 | 채택, 회귀 없음 |
| 아답터 | 0 → 0 | 기각, 개선 부족 |
| 백팩 | 0 → 0 | 기각, 개선 부족 |

[보완 후 기록](run/revalidated.json)에는 원본 파일·검증기 해시, 이전 판정, 새 판정이 함께 있다. 재현: `python scripts/revalidate_alba.py` (API 키 불필요).

## 남은 문제

- A01: 문장 어미까지 바꾼 인용이 있어 차단. 형식 차이로 인정하지 않았다.
- A05: 복합어 분해 후보가 올바른 부분어 구성을 갖추지 못해 차단.
- A09: 문서 제목을 본문 인용처럼 사용해 차단. 정상 질의에 대한 상태 설계도 개선 여지가 있다.
- A12: 원인 불명인데 지원 상태로 응답해 차단.
- A06·A07: 사용자 사전 등록만으로는 부족해 회귀 게이트가 기각. 자동 재처방은 이번 평가 범위에 없다.
- 사후 보완이므로 ‘오류율 일반화 개선’이나 ‘LLM 정확도 향상’으로 주장하지 않는다. 다음 실험은 새로운 질의·지식 부족·반복 생성 조건에서 검증해야 한다. 승인된 24회 한도를 지켜 추가 유료 실행하지 않았다.

## 코드·화면 검증

최종 로컬 전체 검사: **318개 통과, 2개 건너뜀** (208.40초). 선택 의존성·조건부 검사는 전체 결과와 구분한다. `git diff --check` 통과.

검사 명령: `python -m pytest -q`, `clinic baseline`, `node scripts/browser_alba.cjs`.

Kiwi 0.24.1 / 모델 0.24.0 / cong-global 설정을 고정했다. 최신 기본 cong에서 ‘포도’ 분해 기대가 어긋났고, 0.21.0은 다른 카탈로그 계약도 어긋났다. cong-global에서는 분석기·코퍼스·실제 게이트 회귀 검사가 통과하고 기존 기준선 평균 nDCG 0.5839가 유지됐다.

브라우저: 1440·320·390·650px, 저장 결과 24건, 수정안 채택/차단, 입력 변경 무효화, 생성 중 입력 잠금, 수신 취소, 오류 표시, 모드 전환, 다운로드, 가로 넘침을 검사했다. [검사 기록](browser/checks.json). 실제 생성 경로의 **브라우저 전환 검사만** 테스트 응답을 사용했으며, 캡처는 실제 API 저장 응답의 재검증 화면이다.

운영 지표는 현재 프로세스의 요청·상태·오류·바쁨·게이트 요청과 최근 100회 p95이다. 외부 알림·다중 서버 운영·공개 부하 성능을 검증하지 않았다. 기본 서버는 loopback이며 유료 경로는 명시적 활성화와 로컬 토큰이 필요하다. 운영 토큰을 사용자별 인증 시스템으로 주장하지 않는다.
