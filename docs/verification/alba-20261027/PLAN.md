# 사전 평가 계획

실제 호출 전 고정한 파일: cases.json. 12개 작성 사례 × 운영 지식 제공/제거 = 최대 24회. 기존 36개 평가 질의와 겹치는 개발·통합 검증이며 독립 테스트셋 성능이 아니다. 문제 설명에 실패 유형을 암시한 사례도 있어 자동 진단 성능으로 해석하지 않는다.

검색은 BM25 상위 3개, 각 문서 본문 400자. 생성에는 원문 질의, 사용자가 입력한 관찰, 형태소 분석, 검색 상위 3건, 검색된 문서만 제공한다. family/qrels/건강 여부는 평가 출력에만 있고 모델 입력에는 없다. 지식은 프로젝트 작성 요약으로 공식 문서 원문을 직접 인용한 것이 아니다.

## 항목
- 응답 완료/거부/시간 초과/형식 실패를 구분한다. 실패 원문은 키가 노출될 수 있어 저장하지 않고 안전한 오류 코드만 남긴다.
- 인용 검증: 검색된 문서 ID + 본문 부분 문자열 일치. 의미적 사실성 점수로 부르지 않는다.
- 근거 제거 조건: 보류 여부. 문서 없는 상태에서 수정을 제안하면 검증 단계에서 차단한다.
- 수정 후보가 있는 경우에만 기존 회귀 게이트를 실행한다. 표적 개선·다른 질의 회귀·전체 평균을 확인한다.
- 지연/토큰/비용은 호출별 기록. 성공 응답 비용 추정과 실패 포함 예약액을 구분한다.
- 후보가 없는 정상/불충분 결과를 실패 검색 개선으로 세지 않는다.

## 예산과 재실행
모델 gpt-5.4-mini-2026-03-17. 입력 $0.75/1M, 출력 $4.50/1M(공식 모델 페이지 2026-10-27 확인). 요청 JSON UTF-8 11,000바이트 및 출력 800토큰 상한. 입력 텍스트/스키마 바이트와 별도 프로토콜 여유 512토큰 기준 최대 $0.012234를 보수적으로 $0.0125씩 예약한다. 24회 × $0.0125 = $0.30. 자동 재시도/캐시 할인 의존/도구 추가 과금 없음. 원격 일회성 실행 가드와 파일 장부로 중복 평가를 차단한다. 브라우저의 수신 취소가 서버의 이미 시작된 과금을 취소하지는 않는다.

공식 참고: https://developers.openai.com/api/docs/models/gpt-5.4-mini , https://developers.openai.com/api/docs/guides/structured-outputs .

## 초기 발견
최신 Kiwi 0.24.1 환경에서 기존 테스트는 분석 문장의 '포도' 분해 기대와 문서 테스트 개수 두 곳에서 실패했다. 0.21.0 비교에서는 건강 질의와 복합어 계약 등 3개 실패를 확인했다. 좋은 숫자를 위해 모델 버전을 선택하지 않고 현재 분석기의 관측과 검증 기대를 구분해서 해결한다. 실제 생성 평가 전 분석기 선택을 고정하고 전체 회귀 검사한다.
