## 의미 선별과 한계

문자2–5gram TF-IDF로 질의↔질의·본문↔본문·질의↔본문·제목↔제목의 최근접3개씩을 저장했다. 신규 항목별1,000개 목록이며 각 목록에3개 비교 대상이 있다. Kiwi 명사 기반 질의 비교도 수행했다. 유사도는 읽을 대상을 찾는 수단이며 의미 동일성 확률이나 독립성 통과 임계값이 아니다.

어시스턴트가 문서23개와 명사 유사도 상위 질의 쌍25개의 제목·질문·본문 발췌를 검토했다. 문서에서는 같은 개체/사건4건, 제목은 다르나 역사적 사건 중첩4건, 같은 개체의 다른 범위1건, 상하위 관계3건, 기타 관련 개념5건, 다른 개체3건, 표면적 유사성2건, 다른 개최 사건1건을 구별했다. 처음4건 외의19건은 자동 배제하거나 동의 개념으로 합치지 않고 검토 목록에 남겼다. 검토한 질의 쌍25개에서는 같은 정보 요구의 재표현을 확인하지 못했지만 개체·상위 주제 공유까지 없다는 뜻은 아니다.

이는 **AI 보조 의미 선별**이며 사람의 독립 검수나 전체 조합의 의미 비중복 인증이 아니다. a·b·c의 기존15후보 판정을 새 자료의 검수로 세지 않았다. 상세 근거는 비공개로 보존했다.

## 무료 준비 검증

기존 `prepare_v5_independent.py --extra-exposure`를 v3 목록으로 실제 재실행했다. manifest12개 파일 hash를 검증했고 원래 질의·문서 입력 bytes가 이전 준비본과 같음을 확인했다. 기존 준비기에서도 제목/개념 중복4건이 재현됐다. API 호출0회, 새 검색 점수 계산0회, 성능에 따른 자료 교체나 방법 조정0회다.
