# 독립 평가를 위한 공개 사람 판정 자료 조사

**현재 상태 정정:** 과거 v4 준비 기록에서 MIRACL train868질의 전체를 이미 확보했음을 확인했다. 아래254질의의 새 독립 평가 후보 경로는 철회한다. 아래 본문은 발견 전 조사 기록이며, v3 목록은 이후 확보됐다. [후속 노출 감사](HISTORICAL_EXPOSURE_FOLLOWUP_20261101.md)를 현재 상태로 따른다.

기존15후보의 a·b·c 제출은 완료됐다. 이 파일들을 다시 작성할 필요는 없다. 이 조사는 별도의 검색 관련성 정답 확보 문제를 해결하기 위한 후속 작업이며, 새 최종 성능 결과가 아니다.

## 실제 확보와 중복 검사

[MIRACL 공식 데이터 카드](https://huggingface.co/datasets/miracl/miracl/blob/5be20db9509754dadad47689368639fcec739c00/README.md)는 원어민이 질의를 작성하고 문서 관련성을 판정했으며, negative도 실제 판정이라고 설명한다. 한국어 train의 질의868개와 관련성 판정12,767개를 원본 그대로 내려받았다. 관련 판정1,973개·비관련 판정10,794개, 고유 판정 대상 문서10,486개다. 이를 새로 수행한 사람 검수로 표시하지 않는다.

기존 공개 source manifest의 SHA256과 일치하는 한국어 corpus shard3개(총225,970,548 bytes)를 내려받고 전체1,486,752개 passage를 실제 순회했다. 판정 대상 문서10,486개가 모두 존재했고 중복 문서ID가 없었다. 질의ID와 qrels coverage도 일치했다.

검색 실행·모델 호출·성능 열람 없이 다음 순서로 검사했다.

1. 기존 상품36질의·72문서, 이미 준비한 KLUE200질의·300문서, MIRACL dev 전체213질의를 알려진 노출 목록으로 사용했다. 정규화한 고유 질의449개·문서 본문372개다.
2. NFKC·casefold·공백 정규화 후 정확한 질의·문서 본문 중복은0이었다.
3. MIRACL dev의 모든 판정 대상 문서ID에서 기사ID(`#` 앞 부분)를 추출했다. train 질의868개 중610개는 판정 대상 문서 하나 이상이 이 기사 집합과 겹쳤다. 다른 passage라도 제외 대상으로 계산했다.
4. 상품·KLUE의 알려진 제목/개념명과 정확히 겹치는 판정 문서를 가진 질의는26개였다. 앞의610개와22개가 겹치므로 합집합은614개다.
5. 두 제외 조건을 모두 피한 **254질의가 추가 조사 후보**로 남았다. 이를 성능이 좋은 질의로 골랐거나 최종 평가 표본으로 확정한 것은 아니다.

원본 URL·revision·SHA256·집계는 [기계 판독 기록](verification/public-relevance-source-20261101.json)에 보존했다. 상세 질의·문서·판정·제외ID와 실제 실행 스크립트는 비공개 `work/v5-public-relevance-audit-20261101/`에 저장했다. 기존 개발 자료와 KLUE 준비물을 덮어쓰지 않았다.

## 해결한 부분과 남은 경계

새 검색 정답을 전부 직접 만드는 방법 외에, 출처를 확인할 수 있는 공개 사람 판정을 사용하는 경로를 확보했다. 기존 KLUE40,800쌍 전수 검수만이 유일한 경로는 아니다. 다만 다음을 해결하지 않은 채 새 독립 최종 실험이라고 선언할 수는 없다.

- 과거 v3/v4의120질의·문서·개념 노출 목록은 아직 접근할 수 없다. 공개 MIRACL train이라는 사실만으로 과거 실험에서 쓰지 않았다고 가정하지 않는다. 승인된 복호화 경로나 **정답을 제외한 과거 질의·문서·개념 목록**이면 추가 노출 검사가 가능하다.
- 기사ID·정확한 제목 중복 검사는 의미상 유사 질의·개념의 완전한 검수가 아니다. 공개 train은 모델 사전학습에 포함됐을 수도 있다.
- 각 질의에서 판정되지 않은 다른 문서를 비관련 정답으로 채우지 않는다. 판정된 문서만의 재순위 실험과 전체 corpus 검색은 다른 과제이며, 사용할 평가 범위를 최종 점수 열람 전에 고정해야 한다.
- 신규 GPT 후보 생성과 Pair/Context/Rubric 실험은 별도 유료 승인 대상이다. 기존90회 승인은 전부 사용됐고 이번 작업에서 추가 호출은0회다. 신규 후보의 사람 의미 판정을 기존15개 판정으로 대체하지 않는다.

현재 `final_evaluation_ready=false`다. 공개 정답 확보·코드 검증·기존 후보 검수 완료를 독립 최종 평가 완료와 혼동하지 않는다. 연구의 기존 결론인 **RulesPlus 대비 우위 미입증**은 그대로다.
