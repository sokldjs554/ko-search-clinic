# 개발·보정 검수 첫 제출과 판정 의미 확인

d·e Excel을 각각 수령했고 각 Q01의56행, 총112행에 숫자0과 근거 문구가 작성돼 있었다. 나머지는 각1,960행이 빈칸이었다. 원본 파일을 비공개로 보존하고 질문·문서·편집 허용 영역을 대조했다. 질문·문서 변경0, 허용 영역 밖 값 변경0, 수식0이었다.

사용자는 숫자0을 **출력이 정상·정확해 보인다는 뜻**으로 작성했다고 설명했다. 따라서 이112건은 그 의미로 보존하며, 문서가 질문에 관련 없다는 grade0 정답이나 직접 답 근거가 있다는 grade2 정답으로 자동 변환하지 않는다. **제출112건 수령과 검색 관련성 정답 확정은 다르다.** 이 숫자로 검색 점수·모델 성능을 계산하지 않았다.

## 안내와 대응 쌍의 문제

이전 양식은 숫자0/1/2와 문서 출력 확인을 혼동하지 않도록 목적을 충분히 전달하지 못했다. 또한 두 검수자의 질문 순서를 다르게 준비한 상태에서 같은 Q01 시트부터 작성하도록 요청했다. 실제로 두 Q01은 서로 다른 질문이므로 대응하는 질의·문서 판정 쌍은0개다. 겉으로 모두0이라는 이유로 일치율100%나 kappa를 계산하지 않는다. 일치율과 kappa는 null로 남긴다.

이는 검수 안내·작업 구성의 문제로 기록하며 검수자에게 책임을 돌리지 않는다. 질문을 알고 같은 문서 본문에서 답 근거를 찾는지 판단하는 과제로 안내를 명확히 했다. 두 제출의 일시 칸은 비어 있었고 실제 시각이나 날짜를 추정하지 않았다. 수령 시각과 판정 시각은 구별한다.

## 수정한 시범 양식

같은 개발·보정 질문1개와 같은56문서를 동일 순서로 보여 주는 d·e Excel을 별도로 만들었다. 선택 기준은 이전 d Q01이며, 관련성 정답이나 검색 점수로 유리한 질의를 고른 것이 아니다. 보정36질의·최종 후보153질의의 전체 모집단은 바꾸지 않았다.

선택지는 다음 네 문구다. 아래 숫자는 향후 실제 관련성 판정이 들어왔을 때 사용할 코드이며 이번112개의0을 변환하는 규칙이 아니다.

| 새 선택지 | 의미 | 향후 관련성 코드 |
|---|---|---:|
| 직접 답 근거 있음 | 본문이 질문의 답을 직접 뒷받침함 | 2 |
| 일부 관련 근거 있음 | 관련된 근거는 있으나 직접 답을 충분히 뒷받침하지 못함 | 1 |
| 답 근거 없음 | 본문에 질문의 답을 뒷받침하는 근거가 없음 | 0 |
| 판단 어려움 | 질문·문서의 모호함 등으로 판단 불가 | null |

찾은 문장과 이유를 별도 칸에 적고, 우선 두 사람이 같은 처음5건만 제출할 수 있도록 범위를 줄였다. 이는 안내 이해와 제출 연결을 확인하는 개발·보정 시범 단계다.5건만으로 관련성 정답 완성·검수자 신뢰도·최종 성능을 주장하지 않는다. 기존112건, 원래 빈 양식 및 제출본을 덮어쓰지 않았고 새 양식의 모든 판정은 비어 있다. 원래15후보의 a·b·c 제출 완료 상태는 변하지 않는다.

양식에는 합성된 도서관 운영 시간 예시 두 개를 **연습 예시(실험 자료 아님)**로 표시했다. 실험 질의의 실제 답이나 source QA 정답을 예시로 제공하지 않았다. 각 파일은 자기 검수자에게만 전달하고 서로의 답안을 보지 않는 절차를 유지한다.

## 검증과 연구 상태

두 새 파일의 질문·문서 연결56개, 동일한 모집단·순서, 빈 판정 칸, 수식/외부 링크 부재를 재개방해 확인했다. Excel 화면의 실제 렌더링을 검사한 것으로 표시하지 않는다. 질문 ID와 workbook 행의 연결표, 원본 제출 해시, 사용자 설명, 판정 의미를 분리한 레코드는 비공개 `work/v5-relevance-intake-20261101/`에 보존했다. 공개 [수령 집계](verification/calibration-intake-20261101.json)에는 상세 질의·문서·행별 판정을 넣지 않았다.

현재 관련성 정답은 미확정이며 신규 검색 점수 계산0, 신규 provider 호출0, 독립 최종 평가 미완료다. v4 성공 실행 원시 자료 부재의 한계도 유지하며 같은 파일·키를 다시 요청하지 않는다. 이번 안내 수정은 기존 LLM90회 결과나 그 사전 분석 프로토콜을 바꾸지 않는다.
