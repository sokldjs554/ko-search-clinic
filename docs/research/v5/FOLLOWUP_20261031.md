## 실제 준비된 유료 개발 실험

- 모델 `gpt-4.1-mini-2025-04-14`; 표현 쌍/문맥/루브릭 모두 동일 snapshot.
- [공식 모델 가격](https://developers.openai.com/api/docs/models/gpt-4.1-mini): 입력 $0.40/백만, 출력 $1.60/백만. 캐시·Batch 할인은 상한에 반영하지 않는다.
- [공식 종료 일정](https://developers.openai.com/api/docs/deprecations): 2026-10-14 deprecation 공지, 2027-01-14 종료 예정. 현재 계정 접근은 실제 GET으로 확인했지만 미래 실행 가능성을 보장하지 않는다.
- 최대90회, 요청당 입력12,000/출력2,000토큰. 총 입력1,080,000/출력180,000토큰, 예약 상한 **$0.72**.
- 입력은 전체 wire prompt/schema UTF-8 byte수+1024로 보수적으로 계산한다. API가 확정한 tokenizer 값은 아니며 응답 usage와 구분한다. 초과 요청은 자르거나 몰래 다른 모델로 보내지 않는다.
- 출력상한은 API에 전달하며, 호출 전에 전액 예약을 fsync한다. timeout·usage 불명·예외는 해당 예약을 유지하고 후속 호출을 중단한다. 자동 재시도/자동 재개 없음. 명시적 중단·누락 결과도 보존한다.
- usage×고정 단가는 비용 추정이며 실제 청구액으로 표시하지 않는다. 원시 응답·usage·예외상태·호출별 시간·후보/요청/계획 hash를 비공개로 보존한다.
- 모델 응답은 strict JSON schema 후 기존 semantic envelope/patch coverage/인용 위치 검증을 거친다. 입력 문서의 지시는 데이터로 취급한다. confidence0.8은 사전에 고정된 기준일 뿐 보정된 최적값이나 개선 확률이 아니다.

승인에는 정확한 plan hash·모델·호출수·비용이 포함되어야 한다. GitHub 실행은 별도 승인 파일만 추가한 전용 커밋과 승인한 소스 커밋을 확인한다. 코드 준비 커밋은 유료 생성을 실행하지 않는다. 동일 승인 커밋 재실행도 거부한다. 상세 응답/labels는 로컬 수신자에게 암호화한 artifact만 전송한다. [원격 실행·복호화](REMOTE_EXECUTION.md).

## 무료로 실제 재계산한 기준선

## 독립 평가 준비와 사전 기준

[새 자료 출처·해시·노출 점검](INDEPENDENT_DATA.md), [사람 검수 양식·불일치 처리](HUMAN_REVIEW.md).

KLUE MRC 사람 QA 정답은 검색 관련성 qrels가 아니다. 현재160개 answerable/40개 unanswerable 출처 proxy가 있고, 나머지40,600쌍은 미판정이다. 미판정을0점으로 채우거나 unanswerable을 corpus 전체 무관으로 간주하지 않는다. source ID/질의→정답 문서 연결 정보는 private에만 두며 공개 입력과 검수표에서는 제거했다. 두 사람의 독립 관련성 검수와 제3자 조정은 아직 수행되지 않았다.

정확히 일치하는 기존36질의/72문서/가용 MIRACL213질의와의 중복은0이다. 암호화120의 완전한 노출 목록, MIRACL passage 원문, 개념·준중복 검수는 부족하다. 그러므로 final_evaluation_ready=false다. 모델의 사전학습 노출도 배제할 수 없다. QA 장문 검색은 상품 단문 검색을 대표하지 않는다.

[고정 비교 계약](COMPARISON.md)은 Rubric의 전체 nDCG@10을 주지표로 삼는다. 두 반복은 질의 안에서 평균한 후 개념군 bootstrap2000회로 분석한다. NoRepair/RulesPlus 두 비교에 Bonferroni 보정97.5%구간을 적용하며 **두 하한 모두 +0.01 이상**이고 정상 질의의 어느 지표도 악화되지 않아야 사전 수치 조건을 충족한다. Pair/Context 비교와 임계값 sweep은 탐색적이다. 이런 보수적 조건을 통과하지 못하면 우위 미입증으로 기록한다. 데이터/검수/노출/생성 출처가 미완성인 상태에서는 수치 조건이 좋아도 최종 우위 주장 자체를 차단한다.

[전체 최신 상태](verification/final-status.json), [PR3](https://github.com/sokldjs554/ko-search-clinic/pull/3). 이전 최종 bda6b7c CI 성공 기록을 final-status에 바로잡았다. AI 코드 검토의 네 가지 중요 문제(원시 응답 연결, 중단 실행 분모, 상세 결과 경로, Windows 키 권한)를 회귀 테스트로 고쳤다. 368개 파일의 암호화→복호화 바이트 일치와 상세36/공개0질의 브라우저 검사를 확인했다. 후속 변경은 로컬 전체 pytest 652 passed, 2 skipped(선택적 PostgreSQL/규모 계층), baseline 통과다. 원격CI는 코드 반영 후 별도로 확인한다.

```bash
python scripts/prepare_v5_development.py --out work/new-development
python scripts/run_v5_judges.py --bundle work/new-development/candidates.json --out work/new-plan.json
python scripts/prepare_v5_independent.py --download
# 실제 호출 없이 준비되며, 같은 출력 경로를 다시 쓰면 실패한다.
```

분리된 freeze→assemble→score와 호출·암호화 명령은 위 비교/원격 문서를 따른다. 원본 v3/v4와 기존 결과, 처음 생성한 mock evidence는 덮어쓰지 않는다. API 키·복호화 private key·상세 데이터는 커밋하지 않는다.

면접에서 현재 설명 가능한 추가 성과는 실제 모델 접근·비용 제한·실패 보존 경로, 통제된 선택기 비교 계약, 새 평가 후보의 출처와 검수 공백, 무료 RulesPlus 기준선의 정상 검색 악화 확인이다. 실제 LLM 의미 검증의 효과와 독립 성능 우위는 아직 설명 가능한 성과가 아니다.

### Windows CI 실패와 수정 기록

첫 후속 CI [41181102823](https://github.com/sokldjs554/ko-search-clinic/actions/runs/41181102823)는 Ubuntu652통과, Windows640통과/12실패였다. Windows 개인키 ACL 단계가 private bytes를 쓰기 전에 차단됐다. 빈 파일 진단에서 직접 Python 실행은 성공하고 CI와 같은 PowerShell7 부모 아래에서는 Windows PowerShell5.1의 Set-Acl 모듈 로딩이 실패함을 재현했다([진단](https://github.com/sokldjs554/ko-search-clinic/actions/runs/41181718593)). 자식 프로세스가 잘못된 PSModulePath를 상속하지 않게 하며, ACL/소유자 검증을 유지하도록 수정했다. 환경 변수 이름의 대소문자에 대한 회귀 테스트도 추가했다. 실패 기록은 보존하며 최종 성공은 별도 CI 결과로 확인한다.

이어진 CI [41181873954](https://github.com/sokldjs554/ko-search-clinic/actions/runs/41181873954)에서 ACL 검증은 해결됐고, Windows ZIP 이름 정규화 검사1건이 남았다(653통과). 역슬래시를 포함한 원래 ZIP 이름이 라이브러리에서 변경되기 전에 orig_filename으로 검증하고, fixture도 실제 wire 이름을 보존하도록 수정했다. NUL/역슬래시 정규화를 Linux에서도 재현하는 회귀 테스트를 추가했다.
