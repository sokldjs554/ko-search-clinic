## 제출 문장 기준

‘공고 기술을 모두 갖췄다’보다 ‘Python으로 RAG 진단 서비스를 연결하고 실제 응답을 평가했으며, 잘못된 인용·수정이 적용되지 않도록 검증했다’가 근거에 맞는다. 4건 채택은 12개 작성 사례 중 후보 6건을 개별 세션에서 검사한 결과다. 실제 고객 검색 개선, 모델 일반화 성능, 독립 구현 경력으로 표현하지 않는다.
